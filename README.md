# FreshFirst – Perishable Stock Verification Register

## Project Overview

A web-based system for managing perishable stock, verifying expiry dates and storage temperatures, assigning priorities, and maintaining activity history.

## Team Members and Responsibilities

- **Rutika:** Database – Data and Integrity
- **Basamma:** Frontend – User Interface
- **Khushi:** Backend and Testing – Backend Development and Validation

## Current Development Stage

Database development and database evidence preparation completed. Frontend and backend integration will continue according to the team workflow.
